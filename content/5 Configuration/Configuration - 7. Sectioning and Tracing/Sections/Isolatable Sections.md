# Isolatable Sections

See [[../../../3 Overview/Network Sections|Network Sections]] for an overview and the data model and what isolatable sections are.

Isolatable Sections do hardly need configuration.
As long as the attributes [[../../../8 API/Results/Connection Or Path Results/BiDirectional|BiDirectional]] and [[../../../8 API/Results/Connection Or Path Results/Barrier|Barrier]] are set during the [[../../../4 Getting started/Connectivity Extraction Process|Connectivity Extraction Process]], the software will do the rest according to the options you choose one the [[../NetCon feature sources|NetCon feature sources]].

## Computation from Source

Isolatable Sections are computed starting from the [[../../../3 Overview/3.5 Commodity Networks/Sources|Sources]] in the network.
By default, if connections are cannot be fed from a source, they will not have an Isolatable Sections.
Thus, if a connecton *can* be reached from source, even if [[../../../8 API/Results/Connection Or Path Results/Barrier|barriers]] are currently blocking the commodity, they will have an Isolatable Section.

![[../../../Zimages/option_generate_isolatable_sections.png|option_generate_isolatable_sections.png]]

### Include Unfed Isolatable Sections

If you want *every* connection always to have a Isolatable Section, even if they are on [[Islands|Islands]] that cannot be reached from the source, you can set this changing the `Include Unfed` option.
The computation will cost slightly more time.
The advantage is that now you can also use Isolatable Sections for see how parts of the network that cannot be fed by a source a clustered together.

![[../../../Zimages/option_generate_unfed_isolatable_sections.png|option_generate_unfed_isolatable_sections.png]]

## Materializing Isolatable Sections
It is possible to persist the sectioned network by using the following the [[../NetCon feature sources|NetCon feature sources]] source collections:

* `NetConConnection` contain connections stored in a Network and the relations it have to IsolatableSection in its [[../../../8 API/Results/Connection Or Path Results/IsolatableSectionId|IsolatableSectionId]] field.
* `NetConIsolatableSection` contains a record for every section. Its fields are described below.
