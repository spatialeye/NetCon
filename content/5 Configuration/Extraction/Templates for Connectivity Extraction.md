# Templates for Connectivity Extraction

The following seProject configuration templates are available to start working with:

- template_netcon_base_yyyyMMdd.seProject
- template_netcon_model_yyyyMMdd.seProject
	- Note that there definition in this configuration should never be modified; keep it as you received it from Spatial Eye.
- template_netcon_section_yyyyMMdd.seProject
	- This configuration is for materializing flow and sections. Also certain traces, asset hierarchy data, etc. can be made available in export tables.
- template_netcon_tools_yyyyMMdd.seProject
	- This configuration has been merged with the section one. It is used for materializing certain traces.
- template_netcon_uvabackup_yyyyMMdd.seProject
- template_netcon_viewer.seProject
- template_netcon_traceapi.seProject

Never modify the templates before saving them under your own name.
Please, report problems at [support](https://support.spatial-eye.com).
