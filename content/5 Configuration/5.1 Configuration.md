# Configuration

This section describes how to configure NetCon network connectivity for use.

For configuration with the 'desktop' software, Spatial Workshop or GeoSpatial Analysis (Ultimate) is used. The configuration files is saved with the extension '.seProject'. 

The following configurations can be made:

1. the [[../4 Getting started/Connectivity Extraction Process|Connectivity Extraction Process]], in order to daily update the NetCon connections that are used.
2. In addition Near Real Time or Data Patches can be used on top of those with [[./Configuration - 9. Overlay and Near Real Time Networks/Overlay - 1. Introduction to Overlay Networks|Overlay Networks]] to have direct changes.
3. For analysis and network statistics one can use a configuration for [[../6 Use/Data Quality/Data Qualtity Assetment|Data Qualtity Assetment]] and other built-in analysis tooling.
4. For use of NetCon functionality in other applications, one can make [[../8 API/NetCon API Calls|NetCon API Calls]].
5. To simply view the network, its flow, and sectioning in a web browser configure [[../4 Getting started/Viewing Connectivity|Viewing Connectivity]].
6. To interact with the network, do what-if scenario's with outages, etc. configure [[./Configuration - 10. NetCon Portal/NetCon Portal - 2. Admin portal configuration|NetCon Portal - 2. Admin portal configuration]].
