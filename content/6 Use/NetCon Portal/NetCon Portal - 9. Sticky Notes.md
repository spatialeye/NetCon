# NetCon Portal - 9. Sticky Notes
Sticky Notes are a GeoNotes object presented as an annotation layer in the NetCon Portal application. It can be used to quickly annotate an event on the map.  
## Add Note
Button is always available at the top of the map. After clicking, users are prompted to enter a location where the Sticky Note will be placed. After that a form is displayed to enter a note. After Save, new Sticky Note will appear on the map.
## Hide
The Hide button is always available at the top of the map. After clicking it, Sticky Notes are minimized (just a symbol is displayed). 
## Edit (pencil icon)
The Edit button is available in the header of the Sticky Note. The button opens a form to edit the note. 
## Set Note to Removed (x icon)
The X button is available in the header of the Sticky Note. This button sets the status of the Note to Removed (it does not delete the note yet). 
## Delete
Notes that have status Removed display the button Delete. This button deletes the Note record from the GeoNotes DB. 
## Move
The move action is only possible for Sticky Notes that are not set as Removed. Simply drag the Sticky Note to a new place in the map. The location will be updated in the GeoNotes DB.
