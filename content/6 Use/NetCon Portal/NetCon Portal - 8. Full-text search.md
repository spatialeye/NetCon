# NetCon Portal - 8. Full-text search
Full-text search allows the users quickly locating GIS or Connection records. The best use is to search based on unique identificators. But other values such as Status can be used to narrow the search as well. 
There are two searches configured: **Outage portal** and **NetCon**. Outage portal contains source GIS objects such as water pipes as well as Outage and Observation records. NetCon search contains only Connection records but offers more filter options to narrow down the search result.
