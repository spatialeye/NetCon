# ControlSectionId

Type of: _boolean_

Unique id of the Control Section this connection is in. Control Sections are fed from important barriers (e.g. 'circuit breakers') behind a station or installation. They typically denote how operators manage sections of the network leaving a station.

See also [[../../../5 Configuration/Configuration - 7. Sectioning and Tracing/Sections/Control or NetCongestion Sections|Control or NetCongestion Sections]].
The criteria of custom defined sections are specified in the [[../../../5 Configuration/5.1 Configuration|5.1 Configuration]].
