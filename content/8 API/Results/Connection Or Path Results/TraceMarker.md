# TraceMarker

Type of: _integer_
_

TraceMarker enumerator showing a special marking of this connection in the trace results. '0' = none, '1' = matching start criteria, '2' = matching yield criteria, '3' = both. Other values are '4' = waypoint, '16' = make barring and '32' = make conducting.

See also [[../../../6 Use/Enumerators/NetCon TraceMarker Enumerator|NetCon TraceMarker Enumerator]]. The values 'make barring' and 'make conducting' indicate for the network operator what to do with an [[../../../6 Use/Outage Impact Analysis|Outage Impact Analysis]].
